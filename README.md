## ✨ Features
- **Waybar Integration:** Custom status bar with `config1.jsonc` and `style1.css`.
- **Rofi Theme:** Beautiful "buscgirl" theme for application launcher.
- **Power Menu:** Clean system actions menu with powermenu.sh.
- **Tiri Configuration:** Optimized for keyboard-driven workflow.
