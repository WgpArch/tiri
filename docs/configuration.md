# Configuration

This repository contains a highly customized Tiri window manager setup with Waybar and Rofi.

### Tiri Window Manager
- `configs/tiri/config.kdl`: Main Tiri configuration file.
- `configs/tiri/config.kdl_bak`: Backup of the main configuration.

### Waybar Status Bar
- `configs/waybar/config1.jsonc`: Waybar configuration for Tiri (uses `config1.jsonc`).
- `configs/waybar/style1.css`: Custom CSS styling for Waybar.

### Rofi & Power Menu
- `configs/rofi/buscgirl.rasi`: Custom Rofi theme configuration.
- `configs/rofi/powermenu.sh`: Power menu script for system actions.

> **Note**: The `config.jsonc` and `style.css` files in `/etc/xdg/waybar/` are for SwayWM and are **not** part of this Tiri configuration.
